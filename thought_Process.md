## Current decisions: access, content, and saves

- **DATA-01 — Sign-in is not edit approval (2026-09-05; 2026-10-03).** Guests/waiting accounts browse; Google/email signup, confirmation/status, and approval recheck stay available. Startup hides access panels until session/approval resolves; known approval is not a cached permission grant. Editing requires existing approval. Database policies enforce contributor/owner and own-review boundaries. Catalog administration derives owner identity server-side, never from client claims. [Account rules](PRODUCT.md); [regressions](REGRESSION_GUIDE.md).
- **DATA-02 — Separate shared description from personal opinions (2026-09-28).** Authored restaurant/dish reviews require a rating. Metadata, photo-only saves, likes, and review edits must preserve other fields and people’s reviews. Drafts are account/parent scoped; save or explicit discard clears the matching draft. Keep own-review actions, other-review reading, and owner moderation.
- **DATA-03 — Deletion is recoverable (2026-07-23 onward).** Indefinite Trash retains originals, relationships, and Storage files; whole-dish Trash includes reviews/photos/likes. Own-review Undo lasts ten seconds, pauses while focused, and guards the exact deletion timestamp. Offline cloud review deletion is blocked. Compensate only newly uploaded unreferenced files from a failed commit; unknown/historical files are not garbage.
- **DATA-04 — Retry without duplication/lost work (2026-09-07; 2026-09-28).** Per-account durable operations use stable entity/operation UUIDs, transactional RPCs, and idempotency receipts. Reconciliation preserves pending places/dishes. Partial place/review failure reuses its ID. Cache failure after cloud acknowledgement is not a cloud-save failure. Keep explicit unsynced state and network/access retry.
- **DATA-05 — Imports remain deliberate (2026-07-23 onward).** Keep preview, duplicate review, explicit local/cloud destination, safe merge, and explicit local replacement. Cloud import uses transactional/RLS paths. Imported account likes become Earlier likes, never impersonated accounts. Preserve compatible export/record formats; use disposable fixtures.
- **DATA-06 — Do not guess identities (2026-10-03/04).** Likes are independent account reactions; earlier typed names stay Earlier likes. Visits record the current display name and preserve historical names/commas verbatim, not guessed attendance accounts. Reviews/dishes/historical visits inform shared Visited status. Private Bookmarks remain separate.

## Operational lessons and unresolved risks

- **OPS-01 — Git is not schema rollout.** Missing production capture RPC caused save failures until approved 2026-08-08 migration. Lookup/catalog/likes applied 2026-10-03; photo/ownership/reliable-save migrations in September. Provider/source timestamps may differ; thumb-path application recorded twice, columns once. Inspect schema/history before claiming pending, rerunning, or removing migrations; old diary statuses are historical.
- **OPS-02 — Preserve auth/PWA/delivery contracts.** Confirm empty cloud data before showing the hero; initial HTML keeps it hidden. Builds stamp ignored dist/release metadata, not source. Keep config/Maps/health routes, assets, inherited bindings, and owner release diagnostics. Compare controller/document build IDs: matching shells stay visible; older/legacy shells reload once. Verify live HTML/app/SW stamps. Never clear the only unsynced browser copy. [OAuth/PKCE/SW regressions](REGRESSION_GUIDE.md).
- **RISK-01 — Playlist limits.** Concurrent normalized cloud names lack atomic server uniqueness; fixing needs approved schema work. Restaurant-array exports omit standalone empty catalogs. [Evidence](docs/PLAYLIST_CREATION_2026-10-04.md).
- **RISK-02 — Review concurrency.** Cached-source draft checks are not database concurrent-edit locks; keep the safeguard without claiming stronger guarantees.
- **RISK-03 — Device coverage.** Pixel navigation/taps passed; comprehensive physical iOS/Safari, keyboards, screen-reader, and production failure paths remain unverified. No universal/120fps claim. [Report](plans/render-motion-audit-2026-10-13/PIXEL_LIVE.md).
- **RISK-04 — Intentional exceptions.** Unknown Storage objects were retained. Public ID/count aggregates and owner-guarded catalog RPCs have intentional advisor findings; do not reflexively remove access. Last recorded leaked-password protection was disabled on Free; no unauthorized upgrade/settings change. Re-check relevant live settings rather than relying on historical counts.
