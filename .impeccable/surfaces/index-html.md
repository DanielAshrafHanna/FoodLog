# FoodLog primary surface

- **Scope:** `index.html`, `styles.css`, and the browser application behavior in `app.js`.
- **Mode:** Operate.
- **Audience:** Dany, friends, and public visitors browsing the shared collection.
- **Job:** Remember restaurants and dishes, maintain the shared journal, and choose the next place together.
- **Primary actions:** Find a place, inspect friend opinions, add or edit an entry, and add to Bookmarks.
- **Content:** Real restaurants, dishes, ratings, reviews, photos, playlists, maps, and approval state. Never fabricate production content.
- **Constraints:** Preserve every existing capability and regression safeguard. Production data and deployment remain untouched without approval.
- **Direction:** Porcelain & Bronze: warm white light mode, neutral charcoal dark mode, restrained bronze emphasis, existing editorial type and browsing structure. Dany confirmed this refinement on October 3, 2026.
- **Memorable moment:** The selected restaurant ticket aligns with the photo-led detail stage, making the group decision feel like an order moving from shortlist to table.
- **Spatial rhythm:** Related controls use 8px gaps; groups use 12–16px; sections use 24px. Keep action sheets, long review names, mobile sticky headers, and narrow footers clear. Preserve native navigation, selectable review prose, and the approved page zoom lock.
